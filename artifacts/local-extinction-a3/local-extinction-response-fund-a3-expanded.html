지방소멸대응기금 확장 운영체계

인구감소지역 지정부터 국비 출연, 투자계획 평가·배분, 지방예산 편입, 세부사업 집행, 성과환류까지. 기존 기금 프로세스(G0–G7)를 축으로 상위 자격층과 하위 집행·책임층을 한 장에 연결. Korea100 연결선 규칙(흰 halo·채운 화살촉·선종 구분)으로 가시성 강화.

맵이 답하는 질문

  • 누가 대상이 되고
  • 어떤 계획으로 돈을 받으며
  • 어디서 집행되고
  • 무엇으로 다시 평가되는가

한 줄 구조

지정 → 출연 → 계획 → 평가 → 배분 → 예산 → 집행 → 성과 → 다음 배분

  • 기존 카드의 G0–G7을 가운데 축으로 유지
  • 앞에 대상 지정·국비 출연을 붙임
  • 뒤에 현장 집행·주민 체감·환류를 붙임
  • 이번 판: 연결선·화살표 명시

재원 비교 레일

지방소멸대응기금평가·투자계획 기반 차등 배분. 한시 출연, 광역 25% / 기초 75%.
지방교부세공식 산식 배분. 일반재원 성격이 강해 계획 평가형과 결이 다름.
고향사랑기부금기부·답례·기금사업. 자발적 유입 재원으로 규모·예측가능성이 다름.
균특/기회발전사업·특구 단위 지원. 기금의 ‘지역 패키지 투자’와 중첩 점검 필요.

핵심 병목

  • 하드웨어형 사업 편중 → 부지·인허가 지연 → 집행률 부진
  • 단년도 계획 관행 → 중장기 전략사업 약화
  • 유사 공모사업 중복 → 기획 부담·성과 분산
  • 인구감소 완화 성과의 단기 입증 곤란
  • 의회 심의에서 집행률 반복 질타

법적 앵커

  • 지방자치단체 기금관리기본법 제22–29조
  • 시행령 제20–25조 (제출기한·성과·협약)
  • 인구감소지역 지원 특별법 / 지방분권균형법
  • 지방소멸대응기금 배분 기준 고시
  • 지방재정법 예산편성 · 지방자치법 의회 의결

주요 연결 (이번 판 강조)

  • 지정 → 기초 자격 / 출연 → 배분기준 → 공제회 운영
  • 광역·기초 투자계획 → 제출·평가 → (보완 루프) → 배분
  • 배분 통보 → 세입 편성 → 의회 심의 → 현장 집행
  • 집행실적 → 성과분석 → 차년도 배분·제도개선 환류
