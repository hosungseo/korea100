# 법제처 API 복구 후 재개 절차

현재 상태: **법제처(law.go.kr) 전 사이트 점검 중** — DRF·메인·법령 상세 모두 응답 불가.
그래서 사례 128건의 법령 인용은 **미검증**이며, 전 사례 각주에
`근거(인용 법령 — 법제처 원문 대조 대기)`로 상태를 명시해 두었다.

## 0) API 살아있는지 한 줄 확인

```bash
curl -s "https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=law&type=XML&query=%EA%B1%B4%EC%B6%95%EB%B2%95" | head -c 120
# XML(<LawSearch>…)이 나오면 복구. "시스템 점검"/HTML이면 아직.
```

## 1) 전수 대조 실행

```bash
cd ~/korea100/artifacts/ax-case-studies
node verify-law.mjs            # 즉시 실행 (점검 중이면 SKIP, 종료코드 2)
node verify-law.mjs --wait 240 # 복구까지 3분 간격 폴링 후 자동 실행
LAW_OC=<본인아이디> node verify-law.mjs   # 개인 OC 발급 시 (호출 한도↑)
```

- 결과: `법령 미검출` / `○○법에 제N조 없음` 형태로 파일·노드까지 지목
- 캐시는 `.lawcache/`에 쌓임 — 재실행 시 빠름. 이상하면 `rm -rf .lawcache`

## 2) 우선 확인 목록 (작성 에이전트·감사관이 스스로 신고한 것)

**조문 번호 자체가 불확실**
- 국가계약법 시행령 제9조 / 농지법 제54조 / 재난안전법 제38조 (중앙부처 담당 신고)

**조문 제목이 틀렸을 가능성**
- 법원조직법 제57조 "(재판 공개)" → 실제 "재판의 공개"로 추정
- 형집행법 제16조 "(신입자의 수용)" → "신입자의 수용 등"으로 추정
- 기상법 제14조, 여객자동차법 제23조, 국토계획법 제22조 (제목 미기재 또는 미확인)
- 수입식품안전관리 특별법 제20·21조 — 제목 불일치로 현재 번호만 표기 중

**적용 대상 자체가 의심**
- 공공기관·지방공사에 민원처리법 제9조·제27조 직접 인용 4건
  (LH 홈픽스, 건보공단 나이스-콜, 국민연금 지식검색, 포천도시공사)
- 소방청 구급 플랫폼: 소방기본법 vs 119구조·구급에 관한 법률 조문–단계 대응

## 3) 수정 후 재빌드·재계산

## 4) 초록 승격 패스 (검증이 끝나야 의미 있는 작업)

현재 추론 비율이 **82.8%**로 높은데, 이는 "확신 없으면 조문을 지어내지 말고 파랑으로 두라"는
작성 원칙의 결과다. 검증이 끝나면 근거가 확실한 단계를 `inferred` → `statute`로 승격하고,
그 뒤에 아래 두 수치를 **반드시 재계산**해야 한다.

- **인사이트 【1】의 "대체 542건 중 100%가 규정 밖"** — 여비몬(정밀)에서는 대체 5개 중 4개가
  규정상 의무였다. 초록이 늘면 이 100%는 내려갈 수 있다. 시리즈의 중심 문장이 걸린 수치다.
- **추론 비율 ↔ 대체 수 상관(r=0.40)** — 초록/파랑 비율이 바뀌면 함께 움직인다.
