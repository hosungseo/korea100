# 지방소멸대응기금 — 정책 흐름 릴스

Korea100의 행정 리터러시 방식을 9:16 세로 영상으로 옮긴 포트폴리오 산출물입니다.

## 한 줄 설명

연 1조 원 규모의 지방소멸대응기금이 단순 지급이 아니라, 지역 진단과 투자계획, 평가·배분, 예산·의회 심의, 사업 집행, 다음 해 환류로 이어지는 구조임을 보여줍니다.

## 구성

- `local-extinction-response-fund-reel.mp4` — 최종 검토 영상, 1080×1920, 16초, 무음
- `review/` — 첫 흐름, 업무체계도, 성과 환류, 마감 프레임
- `source/` — HyperFrames HTML 원본과 렌더에 필요한 로고 자산
- `media/mois-logo.png` — 행정안전부 공식 로고 원본

## 영상 구조

1. 기금 → 지역 투자계획 → 평가·배분
2. 주민 의견·지역 진단 → 중기 투자계획 → 평가·보완 → 평가 결과 확정 → 세입·의회 심의 → 세부사업 추진
3. 광역·기초지원계정의 배분과 2027 평가·배분체계 개편 방향
4. 집행 실적·성과 관리 → 다음 해 투자계획·평가 반영

## 디자인 원칙

- Korea100 SVG 연결선: 흰색 배경선 + 의미 색상선 + 흰색 외곽선 marker 화살표
- KRDS를 참고한 단계 표시, 구조화 목록, 상태 위계, 테두리·여백 규칙
- 행정 정보를 설명문이 아닌 검토 가능한 업무체계도로 표현
