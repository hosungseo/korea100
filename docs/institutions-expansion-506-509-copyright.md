# 저작권법 기반 제도 확장 506~509

기준일: 2026-07-19

## 배경

공개 제작 요청(이상구): **저작권·동일성유지권** — 강의안을 편집자가 합의 없이 2시간 분량을 1시간으로 줄여 배포한 사례.  
기존 카탈로그(1~505)에는 저작권법 중심 제도가 없어, 요청 건을 포함해 이용자가 실제로 밟는 경로 4개를 추가했다.

## 요청 사례와의 연결

- **사실관계**: 강의안(저작물)을 편집자가 합의 없이 단축·배포 → 동일성유지권(제13조) 중심, 복제·공중송신·2차적작성 등 재산권 침해 병존 가능.
- **1차 경로**: 시정·배포중단 요구(제123조) → 위원회 알선·조정(507) 또는 온라인 게시 시 전송 중단(508).
- **유의**: 제125조 손해액 추정·법정손해는 저작재산권 중심이며 **저작인격권에는 적용되지 않음**. 등록(509)은 성립 요건이 아니라 추정·대항·일부 구제 선택에 의미.
