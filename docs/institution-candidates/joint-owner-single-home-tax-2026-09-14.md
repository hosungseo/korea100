# 부부 공동명의 1주택자 종부세 특례 · 2026-09-14

- 신규 항목: `joint-owner-single-home-tax-special` (660번)
- 공개 경로: https://hosungseo.github.io/korea100/model/joint-owner-single-home-tax-special/
- 범위: 현행 신청·변경·취소 절차, 비교 안내, 상호 관련 제도 링크. 개인별 세액 계산기와 세제개편안은 포함하지 않음.

## 핵심 확인

1. 6월 1일 기준 혼인·거주자·소유·세대 요건을 확인한다. 배우자나 다른 세대원의 다른 주택·부속토지를 무시하지 않는다.
2. 2026년부터 지분율과 무관하게 공동 소유자간 합의로 납세의무자를 선택한다. 기존 지분율 우선 기준을 재사용하지 않았다.
3. 일반 과세의 인별 9억원 공제와 특례의 합산 후 12억원 공제를 구분한다. 특례는 선택한 사람의 연령·보유기간에 따른 세액공제를 적용하며 한도는 80%다. 공제액 차이를 절세액으로 표현하지 않는다.
4. 신청은 9월 16~30일. 기존 신청에 변동이 없고 요건을 계속 충족하면 반복 신청하지 않는다.
5. 소유자·지분율·납세의무자 변경과 특례 취소는 변경신청 대상이다. 최신 별지 제30호서식과 혼인관계증명서를 안내한다. 등기자료는 담당 공무원 확인사항이다.
6. 납세의무자 본인의 대체취득·상속·지방 저가주택 및 합산배제는 별도 요건·추가 신청을 확인한다. 공동명의 특례만으로 자동 제외된다고 설명하지 않는다.
