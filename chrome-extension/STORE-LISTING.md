# Chrome Web Store 제출 메모

## 단일 목적

Korea100 제도를 검색하고 개인 업무구조도 초안과 근거를 Chrome 사이드패널에서 편집한다.

## 짧은 설명

대한민국 제도를 찾아 개인 업무구조도 초안으로 복제하고, 단계·연결·근거를 정리합니다.

## 상세 설명

Korea100 작업대는 공개된 Korea100 제도 데이터를 Chrome 사이드패널에서 검색하고 개인 초안으로 복제하는 도구입니다. 업무 단계와 연결, 법적 근거를 편집하고 웹페이지에서 직접 선택한 문장을 근거로 보관할 수 있습니다. 초안과 전체 작업대는 JSON으로 백업할 수 있으며, 캡처 원문을 제외한 GitHub·GitLab 기여 제안 패키지를 만들 수 있습니다.

별도 회원가입이나 Google OAuth를 사용하지 않습니다. 즐겨찾기와 초안 목록은 Chrome 동기화 저장소, 초안 본문과 캡처 근거는 현재 기기의 로컬 저장소를 사용합니다.

## 권한 사유

- `sidePanel`: 핵심 편집 화면을 현재 웹페이지 옆에 유지하기 위해 필요
- `storage`: 즐겨찾기, 초안, 근거와 화면 설정을 저장하기 위해 필요
- `contextMenus`: 사용자가 선택한 문장을 명시적 명령으로 가져오기 위해 필요
- `activeTab`: 사용자가 확장 프로그램을 실행한 현재 탭에만 일시 접근하기 위해 필요
- `scripting`: 현재 탭에서 사용자가 선택한 텍스트, 페이지 제목과 정리할 URL을 읽기 위해 필요

## 사용하지 않는 권한

- `identity` 또는 OAuth
- `host_permissions`
- 방문 기록, 쿠키, 클립보드, 위치, 다운로드 권한

## 개인정보 설문 초안

- 웹사이트 콘텐츠: 사용자가 명시적으로 선택한 문장만 처리함
- 사용자 활동: 방문 기록 또는 클릭 이력을 수집하지 않음
- 인증 정보: 수집하지 않음
- 개인 식별 정보: 수집하지 않으며 탐지 시 저장 차단
- 분석·광고·신용·대출 목적 사용: 없음
- 데이터 판매 또는 제3자 전송: 없음

스토어 제출 전에 `PRIVACY.md`를 공개 HTTPS URL에 게시하고, 실제 배포 ZIP의 manifest 권한과 설문 답변을 다시 대조한다.
