# Korea100 작업대 개인정보 처리 안내

최종 수정일: 2026-07-16

## 요약

Korea100 작업대는 별도 서버를 운영하지 않으며, 사용자의 이름·이메일·Google 계정 식별자·OAuth 토큰을 수집하지 않는다. 개인 초안과 웹 근거는 Chrome 확장 프로그램 저장소에만 저장된다.

## 처리하는 데이터

사용자가 직접 만드는 다음 데이터만 처리한다.

- 즐겨찾기한 Korea100 제도 식별자
- 개인 초안의 제도명, 설명, 행위주체, 단계, 노드, 연결, 근거 조문
- 사용자가 명시적으로 선택해 가져온 웹페이지 제목, 정리된 URL, 선택 문장
- 화면 설정과 초안 목록 메타데이터

## 저장 위치와 전송

- 즐겨찾기와 초안 목록은 `chrome.storage.sync`에 저장된다. Chrome 동기화가 켜져 있으면 브라우저 제공자의 동기화 기능으로 전송될 수 있다.
- 초안 본문과 웹 근거는 `chrome.storage.local`에 저장되며 확장 프로그램의 별도 서버로 전송하지 않는다.
- 저장 승인 전 선택 문장은 `chrome.storage.session`에 임시 보관된다.
- 확장 프로그램은 분석·광고·추적 SDK를 포함하지 않는다.

## 웹페이지 접근

확장 프로그램은 사용자가 다음 중 하나를 실행했을 때만 현재 페이지의 선택 문장을 처리한다.

1. 사이드패널에서 **선택문장** 버튼을 누름
2. 선택한 문장의 우클릭 메뉴에서 Korea100 가져오기 명령을 누름

페이지 전체 내용, 방문 기록, 입력 폼, 쿠키를 수집하지 않는다. 저장하는 URL에서는 쿼리 문자열과 해시를 제거한다.

## 개인정보 차단

저장·가져오기·내보내기 전에 주민·외국인등록번호, 이메일, 전화번호, 계좌·카드로 보이는 긴 숫자와 인증정보가 포함된 링크를 검사한다. 탐지되면 저장을 중단한다. 이 검사는 오탐이나 누락이 있을 수 있으므로 실제 사건 당사자의 이름, 민감정보, 비공개 문서를 입력하지 않아야 한다.

## 보유와 삭제

데이터는 사용자가 개별 초안·근거를 삭제하거나 **개인 작업 모두 삭제**를 실행할 때까지 Chrome 저장소에 남는다. 확장 프로그램 삭제 시 로컬 저장 데이터도 Chrome의 확장 프로그램 정책에 따라 제거된다. JSON으로 내보낸 파일은 사용자가 직접 관리한다.

## 제3자 제공

확장 프로그램은 개인 작업 데이터를 제3자에게 판매하거나 제공하지 않는다. 사용자가 직접 만든 GitHub·GitLab 기여 제안 JSON에는 캡처 문장을 제외하고 제도 초안과 출처 링크만 포함된다. 파일 자체에는 계정정보가 없지만 외부 플랫폼에 로그인해 올리면 해당 플랫폼의 계정명이 표시될 수 있다. 파일을 외부 시스템에 올리는 행위는 사용자의 명시적 선택이다.
